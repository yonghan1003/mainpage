# Yong Han Liew — Digital HQ

A responsive, static personal website starter.

## Preview
Open `index.html` in a browser. For best results, serve the folder over HTTP.

## Customize before publishing
- Replace `hello@yourdomain.com` in `index.html` with a public contact email, or remove the contact button.
- Add your GitHub / LinkedIn links when ready.
- Review every project status and description to match what is actually public and complete.
- Add a custom domain and hosting configuration with your chosen provider.
- Optional Google Fonts require an internet connection; system fallbacks are included.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, active section and copyright year
- `assets/favicon.svg` — simple text favicon

This is a static front-end starter, not an authenticated dashboard or backend. Do not put credentials, internal IPs, private financial details or confidential employer information in it.
